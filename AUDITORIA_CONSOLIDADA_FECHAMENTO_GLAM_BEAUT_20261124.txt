2. REVISÃO ESTÁTICA ADMIN
- Login exige autenticação Supabase e papel admin ou manager na tabela user_roles.
- Produtos novos são criados inativos.
- Variantes novas são criadas inativas.
- Estoque é movimentado via RPC admin_adjust_inventory; não é editado diretamente.
- Upload de imagem valida JPEG/PNG/WebP e limite de 8 MB; valida sessão e papel admin antes do upload.
- O cadastro rápido cria produto, variante e, quando quantidade > 0, movimentação em chamadas sequenciais. Uma falha pode deixar cadastro parcial. Não repetir o lote sem conferência.

3. REVISÃO ESTÁTICA DA VITRINE/CARRINHO/CHECKOUT

- Cartão e sacola usam identificador de variante.
- Checkout exige sessão autenticada, cria pedido pela RPC create_customer_order_idempotent e solicita link de pagamento à Edge Function create-payment.
- Entrega ainda não calcula frete real localmente; mostra aviso de cálculo no checkout.
- “Mais vendidos” não apresenta ranking falso enquanto não houver dados reais.
- Código usa escapeHTML para texto dinâmico em componentes renderizados.
- A revisão foi estática; não houve teste de navegador, pedido real ou pagamento.
