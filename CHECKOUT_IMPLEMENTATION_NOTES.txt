SEQUENCIA DE IMPLEMENTACAO RECOMENDADA
1. Bootstrap do primeiro administrador: usar fluxo seguro do Supabase Auth; criar profile e role admin; nao inserir senha diretamente no SQL nem criar usuario ficticio.
2. Inicializar store_settings e configurar explicitamente WhatsApp, pickup/delivery e demais parametros.
3. Configurar delivery_regions somente com bairros/taxas confirmados pela proprietaria.
4. Criar variantes reais (UUID) e inventario. Ativar produtos apenas apos revisar cadastro, imagem, preco e SKU.
5. Integrar Supabase SDK no frontend com publishable key, autenticar cliente e criar/atualizar profiles.
6. Catalogo: consultar products ativos; relacionar product_variants ativos; UI precisa manter variant_id e qty no carrinho. Estoque nao pode ser consultado diretamente por cliente; usar RPC/edge endpoint seguro se for mostrar disponibilidade.
7. Checkout: coletar endereco estruturado; mapear entrega para delivery ou retirada para pickup; remover forma pagamento local (Pix/cartao/dinheiro) se Checkout Mercado Pago for obrigatorio, ou separar pagamento na retirada como fluxo offline.
8. Chamar RPC create_customer_order; capturar order_id retornado.
9. Invocar create-payment autenticado e redirecionar para checkout_url.
10. Retornos success/pending/failure devem consultar estado do pedido no backend, nao confiar no parametro URL.
11. Testar Sandbox com usuario real de teste, verificar order/purchase, webhook e estado no banco.
12. Fazer deploy apenas apos revisao; manter main intacta ate checkout testado.
